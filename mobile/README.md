# CodexBot Mobile

نسخه موبایلی CodexBot با **Expo SDK 54، React Native و TypeScript** است. این اپ به‌عنوان همراه امن نسخه دسکتاپ طراحی شده و روی پایش بازار، تحقیق، بک‌تست و کنترل‌های ایمنی تمرکز دارد.

## امکانات فعلی

- داشبورد وضعیت حساب و حالت `PAPER` بدون نمایش اعداد ساختگی.
- واچ‌لیست BTCUSDT، ETHUSDT و SOLUSDT با وضعیت اتصال داده بازار.
- انتخاب استراتژی برای بک‌تست و آماده‌سازی اجرای محلی.
- تنظیمات ایمنی با ذخیره محلی در AsyncStorage.
- قفل کامل اتصال و سفارش‌گذاری زنده در نسخه موبایل.
- پشتیبانی از حالت راست‌به‌چپ و نمایش موبایلی iOS، Android و Web.

## اجرا

```bash
pnpm install
pnpm dev:metro
```

یا برای بررسی کیفیت کد:

```bash
pnpm check
pnpm lint
pnpm test
```

این نسخه هنوز به API کلاینت معاملاتی متصل نیست؛ بنابراین قیمت، موجودی و نتایج بک‌تست فقط پس از پیاده‌سازی و اعتبارسنجی لایه داده نمایش داده خواهند شد. کلید API را در این اپ قرار ندهید.
