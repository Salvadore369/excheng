# MTFlow Mobile

پیش‌نمونه‌ی موبایل MTFlow با Expo SDK 54، React Native و TypeScript. این اپ، رابط کنترل و توسعه‌ی همراه برای معماری پیوست است؛ گوشی محل اجرای MetaTrader 5 نیست.

## امکانات پیاده‌شده

- داشبورد وضعیت VPS ویندوز، ترمینال MT5 و کامپایلر MQL5؛ تا زمان پیاده‌سازی سرویس، وضعیت‌ها آفلاین نمایش داده می‌شوند.
- فضای پروژه‌ی محلی با قالب‌های Expert Advisor، اندیکاتور MQL5 و Python؛ ایجاد پروژه، ویرایش متن کد و ذخیره در AsyncStorage.
- واچ‌لیست نمونه‌ی EURUSD، GBPUSD، XAUUSD و BTCUSD بدون قیمت یا داده‌ی ساختگی.
- صفحه‌ی آماده‌سازی بک‌تست با پیش‌نیازهای صریح، بدون اجرای شبیه‌سازی یا نمایش نتیجه‌ی جعلی.
- تنظیمات ایمنی؛ سفارش زنده، اتصال بروکر، API بازار، VPS، کامپایلر و اجرای MT5 در این MVP پیاده‌سازی نشده‌اند.

## اجرا و بررسی

```bash
pnpm install
pnpm dev:metro
```

```bash
pnpm check
pnpm lint
pnpm test
```

برای استفاده از Expo Go، از دستور `pnpm dev` استفاده کنید تا Metro و API قالب با هم اجرا شوند. API فعلی به VPS/MT5 متصل نیست.

## گام بعدی معماری

برای اتصال واقعی، ابتدا باید سرویس امنی روی Windows VPS طراحی شود که احراز هویت، مدیریت پروژه، کامپایل و تبادل وضعیت را از طریق API کنترل کند. اسرار بروکر یا VPS را در اپ موبایل ذخیره نکنید. هیچ سفارش زنده‌ای را بدون طراحی مجزای مجوز، محدودیت ریسک و تأیید کاربر اضافه نکنید.
